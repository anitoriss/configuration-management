# Конфигурационное управление — вариант 26

Ассемблер учебной виртуальной машины (УВМ), первые два этапа практической
работы из сборника № 3 (РТУ МИРЭА, ИКБО-41-25, 2026).

## Этап 1: промежуточное представление

Исходный язык — алгебраические выражения, по одной инструкции в строке.
Пустые строки игнорируются; комментарии начинаются с `#`.

| Операция | Алгебраическая запись | Поля |
|---|---|---|
| Загрузка константы в аккумулятор | `ACC = 191` | A=4, B=191 |
| Чтение памяти по адресу ACC | `ACC = MEM[ACC]` | A=15 |
| Запись ACC по абсолютному адресу | `MEM[359] = ACC` | A=0, B=359 |
| Сравнение >= с записью в память | `MEM[124] = MEM[124] >= ACC` | A=13, B=124 |

Числовые литералы неотрицательные, десятичные. Константа: 0..1023 (10 бит).
Адрес: 0..536870911 (29 бит). Для сравнения адрес слева и справа должен
совпадать. Стадия 1 разбирает команды в `Instruction(name, a, b)`.

## Этап 2: машинный код

Каждая команда занимает ровно 5 байт. Поле A занимает биты 0–3,
поле B (если есть) — начиная с бита 4. Кодирование little-endian:
`word = A | (B << 4)`, затем `word.to_bytes(5, "little")`.
В режиме `--test` печатаются поля и байты в шестнадцатеричном формате.

## Запуск (Python 3.10+, без внешних зависимостей)

Из **корня проекта**, в PowerShell или CMD:

```powershell
python -m src.assembler examples/reference.asm build/reference.bin --test
python -m unittest discover -s tests -v
```

Можно запустить `run.bat` в Windows или `sh run.sh` в Linux/macOS.
Аргументы CLI: `source` — входной текстовый файл; `output` — путь к
двоичному результату; `--test` — вывести промежуточное представление
и последовательность байтов. Без `--test` выводится только число команд.

Пример результата для эталонных команд:

```text
LOAD_CONST: A=4, B=191  -> 0xF4, 0x0B, 0x00, 0x00, 0x00
LOAD_MEM:   A=15        -> 0x0F, 0x00, 0x00, 0x00, 0x00
STORE_MEM:  A=0, B=359  -> 0x70, 0x16, 0x00, 0x00, 0x00
GE:         A=13, B=124 -> 0xCD, 0x07, 0x00, 0x00, 0x00
```

Образец программы: `examples/reference.asm`. Проверки: `tests/`.
Файлы `*.bin` и артефакты Python исключены из Git через `.gitignore`.
