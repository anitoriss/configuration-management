# configuration-management

**Конфигурационное управление · Вариант №26 · Этап 1**

Ассемблер УВМ из практической работы РТУ МИРЭА (ИКБО-41-25, 2026).

## Этап 1 — перевод в промежуточное представление

Формат входного файла: алгебраические выражения, по одной инструкции в
строке. Пустые строки игнорируются, комментарии начинаются с `#`.

| Команда | Пример записи | Поля промежуточного представления |
|---|---|---|
| Загрузка константы | `ACC = 191` | A=4, B=191 |
| Чтение памяти | `ACC = MEM[ACC]` | A=15 |
| Запись памяти | `MEM[359] = ACC` | A=0, B=359 |
| Сравнение `>=` | `MEM[124] = MEM[124] >= ACC` | A=13, B=124 |

Переменная `ACC` обозначает регистр-аккумулятор. Для сравнения `>=`
используется один и тот же адрес чтения и записи. Допустимые значения
константы: 0..1023 (10 бит), адреса: 0..536870911 (29 бит).

Программа преобразует исходные строки в список `Instruction(name, a, b)`.
В тестовом режиме печатаются поля A и B каждой команды. Аргумент пути к
будущему двоичному файлу принимается уже на этом этапе; создание файла
будет реализовано на втором этапе.

## Запуск

Нужен Python 3.10 или новее. В корневой папке проекта:

```powershell
python -m src.assembler examples/reference.asm build/reference.bin --test
python -m unittest discover -s tests -v
```

Также есть `run.bat` для Windows и `run.sh` для Linux/macOS.
Аргументы CLI: `source` — путь к исходной программе, `output` — путь к
выходному файлу для будущего этапа, `--test` — режим вывода полей.

Пример полей команд: `LOAD_CONST: A=4, B=191` и `LOAD_MEM: A=15`.
Тесты находятся в папке `tests`, пример программы — в `examples`.
